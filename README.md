# IEEE Portfolio
Primary portfolio themes:

- IEEE leadership progression
- technical impact and innovation outcomes
- project and initiative execution
- professional branding and discoverability

## Technology Stack

- React 19
- Vite 8
- Tailwind CSS 3
- Framer Motion
- React Router
- Context API
- Lucide React Icons

## Project Structure

```text
ieee-portfolio
src
	assets
	components
	layouts
	sections
	pages
	hooks
	utils
	animations
	data
public
README.md
package.json
tailwind.config.js
```

## Key Features

- dark-first professional design with cyan/electric-blue accents
- interactive IEEE journey timeline
- animated counters, section transitions, and hover interactions
- achievement and initiative cards with measurable impact framing
- skill visualization with animated bars
- certificate gallery with modal preview
- dedicated contact page with professional channels and direct mail composer
- responsive layout optimized for desktop and mobile
- SEO tags, Open Graph metadata, and JSON-LD structured data

## Local Development

1. Install dependencies

```bash
npm install
```

2. Start development server

```bash
npm run dev
```

## Production Build

```bash
npm run build
npm run preview
```

## Notes
- Portfolio data is maintained in `src/data/portfolioData.js`.
- Contact and social links can be updated in the same data file.
